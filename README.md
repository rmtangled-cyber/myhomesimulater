# マイホームシミュレーター

注文住宅の間取り・床材・クロス・家具を、ブラウザの 3D で試しながら決めるためのアプリです。

## 起動

Node.js 20 以上が必要です。

```sh
npm install
npm run dev
```

表示された URL（ふつうは http://localhost:5173 ）をブラウザで開きます。

Windows では `start.bat` をダブルクリックするだけでも起動できます（最新版の取り込み・準備・ブラウザを開くところまで自動で行います）。

## できること

- 間取り（部屋の外形）から壁・窓・ドアを自動で作り、3D で表示する。複数階・土間や車庫の段差・階段の吹き抜けにも対応
- 階を選ぶと、その階より上を隠して中を見られる。「外観」で建物全体を見る
- 部屋ごとに床材・壁クロス・天井クロスを選ぶ。方角ごとのアクセントクロスも設定できる
- 家具を追加して、ドラッグで動かす（R で 90° 回転、Shift+R で 15° 回転、Delete で削除）
- 俯瞰とウォークスルー（W A S D で歩き、ドラッグで見回す）。床をダブルクリックするとその部屋に入る
- 昼・夕方・夜（照明）の切り替え
- 「案を複製」で、A案・B案のように比較する
- Ctrl+Z / Ctrl+Shift+Z で元に戻す・やり直す
- 今の画面を画像で保存する

変更はすべて自動で `plans/<案の名前>.json` に保存されます。

## Claude と一緒に編集する

間取り・素材・家具はすべて `plans/*.json` に入っています。Claude がこのファイルを書き換えると、開いているブラウザに **自動で反映** されます。
画面で動かした家具や選んだクロスもこのファイルに保存されるので、Claude はそれを読んで続きを手伝えます。

たとえば、こんなふうに頼めます:

- 「LDK の床をウォールナットにして、テレビの後ろの壁だけグレージュのアクセントクロスにして」
- 「主寝室にダブルベッドとドレッサーを置いて。ドアの前はあけて」
- 「今の案を複製して、洋室とWICの間の壁をなくした B 案を作って」

いちばんスムーズなのは、**自分の PC で Claude Code を起動してこのフォルダで作業する** 方法です（Claude がファイルを直接書き換え、ブラウザにすぐ反映されます）。
クラウドの Claude Code で作業する場合は、Claude がブランチに push した変更を `git pull` で取り込むと、起動中のブラウザに反映されます。
自分で画面から変えた内容を Claude に見てほしいときは、`plans/` の変更をコミットして push してください。

## 間取りファイルの書き方

`CLAUDE.md` に詳しく書いてあります。要点:

- 単位は mm。x = 東（右）、y = 南（下）
- 階ごとに `floors[]` に分けて書く
- 部屋は `polygon`（壁芯の外形）で書く。壁は自動で作られる
- 窓・ドアは壁芯の上の中心点 `at` で置く

## 注意

画面の色や質感は実物と違います。床材・クロスは、最終的に実物のサンプルで確認してください。
